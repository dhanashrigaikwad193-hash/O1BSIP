# Random Password Generator

## Objective
A Python-based Random Password Generator that creates random passwords according to the user's selected requirements.

## Features
- Allows the user to choose the password length.
- Minimum password length is 8 characters.
- Supports uppercase letters.
- Supports lowercase letters.
- Supports numbers.
- Supports symbols.
- Requires at least 2 valid character types.
- Ensures selected character types are included in the generated password.
- Generates a random password.
- Allows the user to generate another password.

## Technology Used
- Python
- random module
- string module

## How to Run
Run the `Password_Generator.py` file using Python.

## Input Options
1. Uppercase letters
2. Lowercase letters
3. Numbers
4. Symbols

The user must select at least 2 valid character types.
