# BMI Calculator

## Objective
A Python-based BMI Calculator that calculates Body Mass Index and classifies the result into standard BMI categories.

## Features
- Takes weight in kilograms as input.
- Takes height in meters as input.
- Calculates BMI using the formula:
  BMI = weight / (height ** 2)
- Displays BMI rounded to 2 decimal places.
- Classifies BMI as Underweight, Normal, Overweight, or Obese.
- Handles invalid and negative inputs.
- Allows the user to calculate BMI multiple times.

## Technology Used
- Python

## How to Run
Run the `BMI_Calculator.py` file using Python.

## BMI Categories
- Underweight: BMI < 18.5
- Normal: BMI 18.5–24.9
- Overweight: BMI 25–29.9
- Obese: BMI >= 30
