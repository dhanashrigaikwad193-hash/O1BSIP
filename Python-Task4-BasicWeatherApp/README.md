Basic Weather App

Objective

A Python command-line application that fetches and displays real-time weather information for a user-specified city using the OpenWeatherMap API.

Features

- Accepts a city name as input.
- Rejects empty city input.
- Fetches real-time weather data using an API.
- Displays temperature in Celsius.
- Displays temperature in Fahrenheit.
- Displays humidity percentage.
- Displays weather condition.
- Displays wind speed.
- Handles city-not-found errors.
- Handles invalid API key errors.
- Handles network errors and request timeouts.

Technology Used

- Python
- Requests library
- JSON data
- OpenWeatherMap API

How to Run

Run the "Weather_App.py" file using Python.

Enter a city name when prompted. The application fetches the current weather information and displays the results.

API Key

An OpenWeatherMap API key is required to run the application.

For security, the actual API key is not included in this repository.

Example Output

The application displays:

- Current temperature in °C
- Current temperature in °F
- Humidity
- Weather condition
- Wind speed
